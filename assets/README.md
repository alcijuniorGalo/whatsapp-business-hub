# assets/

Ícones e splash do app.

- Coloque aqui o ícone em **1024×1024** como `app_icon.png` e gere os
  ícones Android com:
  ```
  flutter pub add dev:flutter_launcher_icons
  ```
  e a config `flutter_launcher_icons` no `pubspec.yaml` apontando para
  `assets/app_icon.png`.

- Splash nativo (Android 12+): configurado via `flutter_native_splash`
  seguindo o mesmo padrão.
